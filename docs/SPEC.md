# photo-upscaler 仕様書（v0.1 確定版）

## 1. 目的
画質の悪い人物写真やネット・LINEで受け取った画像を、AIで復元・拡大し、
**セブン-イレブンの写真プリント（2L判）** できれいに印刷できるようにする。
自分一人で使う個人用アプリ（人に配らない・お金をもらわない）。

## 2. 対象の画像（想定）
- 人物の写真（全身・上半身）、強く圧縮された小さい画像
- 例：670×2576 px（横:縦 ≒ 1:3.8）。ピクセル数は足りているが、ぼやけ・JPEGの圧縮ノイズ・顔のつぶれがある
- → 必要なのは「拡大」よりも **復元（ぼやけと圧縮ノイズを取って、くっきりさせる）** が中心

## 3. 動かす環境
- iPad Air 11インチ（M3、メモリ8GB）の Safari。ホーム画面に追加して使う（PWA）
- Webアプリ：WebGPU ＋ ONNX Runtime Web（WebGPUが使えない場合はWASM）
- **画像はiPadの外に送らない**（処理はすべて端末の中で行う）
- 置き場所：新しい公開リポジトリ `photo-upscaler` ＋ GitHub Pages
- AIのデータ（1ファイルが100MBを超える）は Hugging Face などの配布元から読み込み、iPadに保存（Cache Storage / OPFS）

## 4. 画面の流れ（1枚ずつ）
1. 写真を選ぶ（写真ライブラリ／ファイル）
2. 切り抜く
3. AI処理（進み具合を表示）
4. 補正前と比べる・顔補正の強さを調整する
5. 写真アプリに保存

## 5. 切り抜き・レイアウト
- 切り抜き枠は、書き出すサイズの比率に固定し、自由に動かせる・ピンチで拡大縮小できる
- 最初は「全身が入る位置」（画像全体がおさまる大きさで、中央）
- 余白は**元の写真を大きくぼかして敷いた背景**で埋める
- フチなし印刷で端が切れたときの目安線（外側から約2〜3mm）を表示する（書き出しには含めない）

## 6. 書き出すサイズ
| サイズ | mm | px（300dpi） | 備考 |
|---|---|---|---|
| **2L判（初期値）** | 127×178 | 1500×2102 | メイン |
| L判 | 89×127 | 1051×1500 | 画質が足りないとき用 |
| はがき | 100×148 | 1181×1748 | ほかの印刷サービス用 |

- 縦向きと横向きを切り替えられる
- 形式：JPEG（品質0.95）、sRGB。印刷用に300dpiの情報を書き込む

## 7. AIの処理
### 7.1 拡大・復元
- 切り抜いた範囲を、本来の画質相当の大きさまで一度縮小してから、**Real-ESRGAN x4plus（写真用）** で4倍に拡大し、書き出すサイズに合わせる
- 縮小する倍率は自動で決め（書き出すサイズ÷4 を目安）、手動でも調整できる
- 画像を小さく分けて（例：256px＋重なり16px）処理し、Safariのメモリ不足を防ぐ

### 7.2 顔補正
- 顔を自動で見つける（軽い顔検出モデルを使う）。複数の顔もまとめて補正する
- **CodeFormer** で補正する（個人利用なので、S-Labライセンスの条件の範囲内）
- スライダー1本で強さを調整する。**初期値は本人らしさ寄り**（CodeFormerの fidelity w ≈ 0.7）
- 補正した顔は、輪郭をぼかして元の画像に貼り戻す

## 8. 補正前と比べる画面
- 真ん中の線を左右に動かして、補正前と後を見比べる
- ピンチで拡大して、顔や細かいところを確認できる

## 9. 性能の目安
- 2L判1枚：約30秒〜1分（M3＋WebGPU）
- 初めて使うときだけ、AIのデータ（約400MB）を読み込む

## 10. 最初の版で作らないもの
まとめて複数枚の処理／文字入れ／顔ごとの個別調整／AIで背景を描き足す機能／イラスト用モデル／ネイティブアプリ版

## 11. 作る順番
1. 写真を選ぶ・切り抜く・ぼかした余白・書き出し（AIなし）
2. Real-ESRGAN（小さく分けて処理する、WebGPU）
3. 顔検出＋CodeFormer＋強さのスライダー
4. 補正前と比べる画面・PWA化・AIデータの保存
5. セブン-イレブンで試し印刷 → 調整
